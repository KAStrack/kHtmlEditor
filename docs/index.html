kHtmlEditor

A rich text HTML editor built from scratch as a drop-in replacement for TinyMCE. Same config, same API, no dependencies, MIT licensed.

Full demo → Read the docs Migrate from TinyMCE
<!-- 1. Include the script -->
<script src="khtmleditor.min.js"></script>

<!-- 2. Initialise exactly like TinyMCE -->
<script>
  kHtmlEditor.init({ selector: 'textarea', plugins: 'lists link image table code' });
</script>

Why kHtmlEditor

    

      
Drop-in for TinyMCE
Same option names, toolbar syntax, editor.* API, events and dialog spec. Rename the global or load the one-line shim.

      
Zero dependencies
One self-contained script. No frameworks, no DOMPurify, no Prism: the sanitiser and highlighter hooks are built in.

      
Safe by default
Everything that enters the editor passes a schema allowlist and an always-on XSS layer tested against a vector corpus.

      
Image and video uploads
TinyMCE's exact upload contract (POST file → {location}) plus media uploads, drag-drop and paste.

      
Accessible
Keyboard-navigable toolbar, menus and dialogs with ARIA roles, focus management and screen reader announcements.

      
MIT licensed
Free for any use, forever. Built for the k-series of projects by KAStrack.
