Options

Generated from the source at build time. Options follow TinyMCE 6/7 names; TinyMCE 4/5 names are translated (see migration).

Types: string, number, boolean, array, object, function, string[], object[], regexp; custom means a validating processor that accepts several shapes (for example false or a string). Defaults are shown as written in the source.

Options accepted for TinyMCE compatibility but without effect: license_key, promotion, cloud_*, icons, icons_url, service_message, referrer_policy (passed to the iframe only).
