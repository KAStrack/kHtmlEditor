# Toolbar buttons

<p class="lead">Use these names in `toolbar`, `toolbar1..9`, `toolbar_groups`, `quickbars_*_toolbar` and `table_toolbar`. Generated from the source at build time.</p>

Kinds: **Button** performs an action; **ToggleButton** shows an on/off state; **MenuButton** opens a menu; **SplitButton** has a main action and a menu; **GroupToolbarButton** opens a nested toolbar. Plugin buttons are available only when the plugin is in `plugins`. Deprecated TinyMCE names (`fontselect`, `fontsizeselect`, `formatselect`, `styleselect`, `lineheightselect`) are accepted as aliases.
