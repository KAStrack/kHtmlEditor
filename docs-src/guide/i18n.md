# Localisation

The UI ships in English. Every string passes through `editor.translate()`, so a language pack translates the whole interface including plugins.

## Loading a language

```js
kHtmlEditor.init({
  selector: 'textarea',
  language: 'de',
  language_url: '/langs/de.js'   // optional: loaded automatically when language is not 'en'
});
```

A language file registers its strings with `kHtmlEditor.addI18n(code, strings)` (or `tinymce.addI18n` via the shim), so TinyMCE language packs load unchanged:

```js
tinymce.addI18n('de', {
  "Bold": "Fett",
  "Italic": "Kursiv",
  "Insert/edit link": "Link einfügen/bearbeiten",
  "{0} words": "{0} Wörter",
  "_dir": "ltr"
});
```

Placeholders `{0}`, `{1}` are substituted when `translate(['{0} words', count])` is called with an array. The special `_dir: 'rtl'` key switches the UI direction.

## Content direction

`directionality: 'rtl'` sets the direction of the content; the `directionality` plugin adds `ltr`/`rtl` buttons that set `dir` on selected blocks.

## Spell checking

`browser_spellcheck: true` enables the browser's spell checker inside the content; `content_langs` lists languages for the `language` toolbar button, which marks selections with `lang` attributes.

## API

```js
kHtmlEditor.addI18n('fr', { 'Bold': 'Gras' });
kHtmlEditor.translate('Bold');     // uses the active language
editor.translate('Bold');
kHtmlEditor.i18n.getCode();         // 'fr'
kHtmlEditor.i18n.setCode('en');
```
